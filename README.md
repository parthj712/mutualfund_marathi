# 🚀 MutualFund Marathi – Financial Awareness Platform

## 🔗 Live Demo

👉 https://www.mutualfundmarathi.com

---

## 🧠 Problem

Many individuals, especially in regional communities, lack access to simple and understandable financial education in their native language. Complex financial jargon and English-heavy platforms create barriers for beginners who want to learn about mutual funds and personal finance.

---

## 💡 Solution

MutualFund Marathi is a content-driven platform designed to simplify mutual fund concepts in the Marathi language. It provides easy-to-understand articles, blogs, and insights that help users make informed financial decisions without confusion.

---

## ⚙️ Tech Stack

* Next.js
* React.js
* Tailwind CSS / Material UI
* Node.js 
* MongoDB 
* REST APIs
* Vercel (Deployment)
